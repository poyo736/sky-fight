SKY FIGHT STEP 23 — PC・スマホ対応PWA

1. フォルダ内の全ファイルをまとめてHTTPS対応の静的サイトへアップロード（GitHub Pages等）。
2. Windows: Edge/Chromeで公開URLを開き、メニューの「アプリをインストール」。
3. Android: Chromeで公開URLを開き「ホーム画面に追加」または「アプリをインストール」。
4. iPhone: Safariで公開URLを開き「共有」→「ホーム画面に追加」。
5. スマホの対戦画面では移動・ジャンプ・パンチ・キック・ガード・必殺技のタッチボタンを表示。

注意：file:// で直接開いた場合、PWAインストールやオフライン機能は動きません。localhost または HTTPS が必要です。
オフライン利用は、最初にオンラインで一度ゲームを開きキャッシュが完了した後に利用できます。
ブラウザや端末によってインストールメニューの名称は異なります。
